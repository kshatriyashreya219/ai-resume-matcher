# AI Resume Matcher 🚀 - Live

**Live Demo:** https://ai-resume-matcher-fkc1.onrender.com
**API Docs:** https://ai-resume-matcher-fkc1.onrender.com/docs

An AI-powered application that matches your resume with any Job Description and gives you a match score, missing skills, and AI feedback using Google Gemini.

### 🔥 Features
- Upload Resume (PDF)
- Paste Job Description
- Get Instant Match Score (0-100%)
- Know Missing Skills
- AI Feedback to improve resume

### 🛠️ Tech Stack
- Backend: FastAPI, Python
- AI: Google Gemini LLM
- Deployment: Docker, Render
- Frontend: HTML, CSS, JS

### 📸 Demo
Live at: https://ai-resume-matcher-fkc1.onrender.com

### How to use?
1. Go to Live Link
2. Upload Resume
3. Paste JD
4. Click Analyze
